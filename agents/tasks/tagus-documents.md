# Task: Documents A, B and C

Write the three archival documents from secret canon 02 as the players would find
them, each with the metadata the engine needs (asset slug, tier, who can find it, where,
what knowledge rows it grants, and the one detail that is wrong).

Document A: the 1921 Bell Expedition Journal. Bell's hand, period diction. An ordinary
cellar; Clara Wren's insistence on a second passage; an unexplained sound; her warning
about the last light. Written so that a reader who later sees Drawing 68-24 recognizes
a sketch in it.

Document B: the 1969 Royce Geological Survey, Prairie Geological Services letterhead.
Two crews, two incompatible maps with real numbers; dry technical prose; a concealed
reference to Drawing 68-24; a recommendation for continued monitoring; a routing slip.

Document C: the 1977 Corporate Security Report on Occult Activity in Mountrail County,
Sloane's office. Deliberately biased. Mixes genuine facts, fabricated evidence (which
the engine must know is fabricated), cattle rumours, excerpts of Sayer's letters with
copied Son of Sam imagery, and concern about the Vigil. Include the forged ritual
diagram's description and the real one it was copied from.
