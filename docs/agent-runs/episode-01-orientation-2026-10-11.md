# Engine Mechanics and Adjudication

## Objective Adjudication
Engine parses player correspondence for binding lines. Engine checks world state for the presence of requested files, transfers, or correspondence classes. Engine verifies the dependent position's state for the required confirmation correspondence. Engine evaluates the predicate as a boolean. Engine awards points and updates objective state. Model narrates the result to the player.

## Edge Cases
Dependent position is on hold or missed turn: verification fails for that round. Player may retry next round. Multiple players request the same file: first order locks the request. Subsequent orders return already processed. Predicate requires a specific date range: engine checks file metadata against the requested range. Mismatch returns insufficient data.

## World Pressure Clock Resolution
The clock escalates deterministically. Player mitigation orders delay progression by one tier per successful action. Tiers resolve at round boundaries. Committee votes override mechanical triggers. DSRD coordination degrades automatically if the Round 7 predicate is met.

## Evidence Tiers
Intelligence requires file requests. Evidence requires correspondence confirmation. Established Finding requires committee acceptance. A finding can be formally established and still be wrong. Contradictory records lower informational structure. Consistent records raise the Convergence Index.
